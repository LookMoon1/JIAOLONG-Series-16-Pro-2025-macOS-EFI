# 文档排版规范

> 本文件定义 `GitHub/` 下所有 Markdown 的统一格式。
> **修改任何文档前请先读本文**，避免同类内容出现不同的排版。

---

## 一、加粗（`**文字**`）

### ✅ 允许加粗的情况

| 场景 | 示例 |
|---|---|
| 警示 / 危险 | `🔴 **会导致系统重启**` |
| **结论性判断**（一句话的答案） | `✅ **已修复**` |
| 与直觉相反的事实 | `AppleHDA **已被移除**` |
| 必须遵守的规则 | `**必须保持 `Disabled`**` |
| 关键数值 | `**3000**`、`**0x40**` |

### ❌ 禁止加粗的情况

| 场景 | 反例 | 应改为 |
|---|---|---|
| 表格第一列（功能名 / 项名） | `\| **Wi-Fi** \|` | `\| Wi-Fi \|` |
| 普通名词 | `**声卡**` | `声卡` |
| 已用代码格式的命令 / 参数 | `**`-v`**` | `` `-v` `` |
| 整句加粗 | `**扬声器 / 耳机孔 / 麦克风均可用**` | 去掉加粗，或只加粗关键词 |
| 同一表格内部分行加粗 | 见下方"表格规则" | 统一不加粗 |

### 🔤 加粗的粒度

加粗**短语**，不要加粗整句。

```markdown
❌ **单独按无反应；Fn + F 功能区按键会导致系统重启。未修复，见上方警告**

✅ 单独按 **无反应**；**Fn + F1–F12 会导致系统重启**（未修复）
```

## 二、表格

### 状态列用 emoji，不用加粗

表格里表示状态的列**统一用 emoji**，**不额外加粗**：

| ✅ 正确 | ❌ 错误 |
|---|---|
| `\| 声卡 \| ✅ \| VoodooHDA 3.7.1 BL \|` | `\| **声卡** \| ✅ \| **VoodooHDA 已修复** \|` |

emoji 语义固定：

| emoji | 含义 |
|---|---|
| ✅ | 完全可用 / 已完成 |
| ⚠️ | 部分可用 / 未验证 |
| ❌ | 不可用 / 未做 |
| 🔴 | **严重问题 / 高风险** |
| 💡 | 提示 |
| 📌 | 重点 |

### 第一列：纯文本，不加粗

```markdown
✅ | 功能 | 状态 | 说明 |
   |------|------|------|
   | Wi-Fi | ✅ | MT7922 原生驱动 |

❌ | **Wi-Fi** | ✅ | ... |
❌ | **Fn 键** | 🔴 | ... |
```

### 表格内可以用的格式

- 行内代码：`` `参数名` `` ✅
- 链接：`[文字](url)` ✅
- emoji：✅
- 加粗：**仅在需要强调某个词时**，且整表风格一致

## 三、行内代码（`` ` ``）

### 必须用行内代码

| 类型 | 示例 |
|---|---|
| 命令、参数 | `` `-v` ``、`` `nvrmacpibl=1` `` |
| 文件路径 | `` `EFI/OC/config.plist` `` |
| 配置项 | `` `Misc → Debug → Target` `` |
| 十六进制 / 数值 | `` `0x40` ``、`` `0x0A43` `` |
| kext 名 | `` `VoodooHDA_BL.kext` `` |
| 函数 / 变量 | `` `IONameMatch` `` |

### 不要用行内代码

- 普通名词：~~`声卡`~~ → 声卡
- 专有名词：~~`OpenCore`~~ → OpenCore（除非指命令）
- 整句

## 四、标题层级

```markdown
# 文档标题（每篇只有 1 个）

## 一、大章节

### 1.1 子章节

#### 细节（慎用，超过 4 级说明结构有问题）
```

**中文序号 + 顿号**，全角：

```markdown
✅ ## 一、硬件
✅ ## 六、声卡：AppleHDA 被移除
❌ ## 1. 硬件
❌ ## 一. 硬件
```

---

## 五、提示块

统一用引用块（`>`）表示提示，**首行用 emoji 标注类型**：

```markdown
> ⚠️ **警告**：删了会导致黑屏。

> 💡 提示：可以用 `--keep-alive`。

> 📌 注意：本机路径与标准不同。
```

**不要**用多个连续引用块表达同一件事。

---

## 六、代码块

必须标注语言：

````markdown
```bash
sudo diskutil mount disk0s1
```xml

```xml
<key>Enabled</key><true/>
```python

```python
import plistlib
```text
````

**禁止**无语言标记的裸代码块（```` ``` ```` 后面直接换行），除非是纯文本对照表：

````markdown
```text
boot-args: -v debug=0x100
```text
````

## 七、列表

- 无序用 `-`（不用 `*` 或 `+`）
- 有序用 `1.` `2.`
- 嵌套缩进 **2 空格**
- 列表项末尾不加句号（除非是完整句子）

```markdown
- 第一项
- 第二项
  - 嵌套项（2 空格缩进）
```

## 八、文件引用

### 站内链接用相对路径

```markdown
✅ [docs/02-关键配置与踩坑.md](02-关键配置与踩坑.md)      ← 同级文件
✅ 见 [README.md](../README.md)                        ← 上级目录用 ../

❌ 见 docs/02-关键配置与踩坑.md（裸文本）
❌ [这里](https://github.com/.../blob/main/docs/02...)（用绝对 URL）
```

### 站外链接

```markdown
✅ [acidanthera/Lilu](https://github.com/acidanthera/Lilu/releases)
```

## 九、标点

- 中文正文用**全角**标点：`，。：；！？（）`
- 代码、路径、英文术语周围不加中文标点
- 中英文之间**加空格**：`使用 OpenCore 引导`
- 数字与中文之间**加空格**：`共 27 条`
- 破折号用 `——`

---

## 十、emoji 使用

**克制使用**。只在以下位置出现：

| 位置 | 允许 |
|---|---|
| 状态表格的状态列 | ✅ ⚠️ ❌ 🔴 |
| 标题的严重程度标记 | 🔴（仅限红线级别） |
| 提示块开头 | ⚠️ 💡 📌 |
| 正文 | ❌ 不要撒 emoji |

## 附：批量检查命令

```bash
cd GitHub

# 1. 找出表格第一列带加粗的行
grep -n '^| \*\*' docs/*.md README.md AGENTS.md

# 2. 找出以加粗开头的列表项（通常是过重的强调）
grep -n '^- \*\*' docs/*.md README.md AGENTS.md

# 3. 找出整句加粗（长度 > 30 字符）
grep -nP '\*\*[^*]{30,}\*\*' docs/*.md README.md AGENTS.md

# 4. 找出无语言标记的代码块
grep -n '^```$' docs/*.md README.md AGENTS.md

# 5. 检查站内链接是否有效
python3 scripts/check_links.py
```
