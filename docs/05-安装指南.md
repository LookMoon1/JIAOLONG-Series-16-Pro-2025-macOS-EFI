# 安装指南

> 本文只讲**如何使用本 EFI**。如果你是**从零安装 macOS 26**，
> 请先看 [NullMoth 1401](https://github.com/nullmoth/1401) 的官方流程。

---

## 前置条件

| 项 | 要求 |
|---|---|
| 硬件 | **必须同为 MUX 独显直连** 的 9955HX + RTX 5060 Laptop（或高度相近） |
| macOS 版本 | 26.7.3 (25G342)；其他 build 需重新评估 `-yyavicnoverify` 风险 |
| NVIDIA 驱动 | 需先安装 NullMoth NVIDIA 驱动 3.0（见下） |
| U 盘 | ≥ 16 GB（OpenCore 在 U 盘上，运行期间不能拔） |

> ⚠️ **本 EFI 不是通用 EFI**。它针对 `MacBookPro16,2` + 上述硬件做了专门调整
> （尤其是 `ExitBootServicesDelay=3000` 与 IONDRVSupport 屏蔽）。
> 用在其他机器上大概率无法启动。

---

## 步骤 1：准备你自己的三码

仓库里的 `config.plist` 已脱敏，**直接使用会导致 iCloud / iMessage 异常**。

```bash
# 用 GenSMBIOS 生成（也可用 OCAT 图形界面）
git clone https://github.com/corpnewt/GenSMBIOS
cd GenSMBIOS && ./GenSMBIOS.command
# 选择 2 (Generate SMBIOS) → 输入 MacBookPro16,2
```

把生成的四项填入 `EFI/OC/config.plist` 的 `PlatformInfo → Generic`：

```xml
<key>PlatformInfo</key>
<dict>
    <key>Generic</key>
    <dict>
        <key>SystemProductName</key><string>MacBookPro16,2</string>
        <key>SystemSerialNumber</key><string>【你的序列号】</string>
        <key>MLB</key>            <string>【你的MLB】</string>
        <key>SystemUUID</key>     <string>【你的UUID】</string>
        <key>ROM</key>            <data>【你的网卡MAC，6 字节】</data>
        <key>CustomSMBIOSGuid</key><true/>
        <key>UpdateSMBIOSMode</key><string>Custom</string>
    </dict>
</dict>
```

**ROM 填写方法**：取本机有线网卡的 MAC 地址（格式如 `AA:BB:CC:DD:EE:FF`），
转成 base64 写入 `<data>`。OCAT 可自动生成，无需手算。

> 不要用别人的 MAC。这块网卡在你机器上是什么地址，就用什么。

## 步骤 2：校验配置

```bash
# 本仓库自带脚本（需要 Python 3）
python3 scripts/validate.py EFI/OC/config.plist
```

或使用 OpenCore 官方的 `ocvalidate`：

```bash
ocvalidate EFI/OC/config.plist
# 期望输出：No issues found
```

---

## 步骤 3：写入 EFI 分区

### macOS 下

```bash
# 挂载 ESP（假设是 disk0s1）
sudo diskutil mount disk0s1
sudo cp -R EFI/* /Volumes/EFI/
```

### Windows 下

用 [MountEFI](https://github.com/corpnewt/MountEFI) 挂载，然后直接复制。

### Linux 下

```bash
sudo mkdir -p /mnt/efi
sudo mount /dev/nvme0n1p1 /mnt/efi
sudo cp -r EFI/* /mnt/efi/
```

> ⚠️ **保留你自己的三码**：如果只是"更新 EFI"，
> 复制完成后要用你备份的 `config.plist` 覆盖回去，否则三码会变成占位符。

## 步骤 4：BIOS 设置

| 项 | 值 |
|---|---|
| Secure Boot | **Disabled**（必需） |
| Above 4G Decoding | 本机无此选项，无需修改 |
| Resizable BAR | 本机无此选项，无需修改 |
| Fast Boot | 建议关 |

## 步骤 5：安装 NVIDIA 驱动

macOS 装好第一次进系统时，**内屏是没有驱动的**（可能黑屏只有鼠标）。

1. 从 [NullMoth nvidia-macos-driver](https://github.com/nullmoth/nvidia-macos-driver) releases
   下载对应版本（本机为 **3.0**）；
2. 解压得到 `nullmoth-nvidia-3.0.tar.gz`，里面是 `install.sh`；
3. 在 macOS 里：

```bash
cd <解压目录>
sudo bash install.sh
```

4. 重启。

> 本仓库**不含** NullMoth 驱动包与任何 kext，纯配置版设计。
> 请从 [nullmoth/nvidia-macos-driver releases](https://github.com/nullmoth/nvidia-macos-driver/releases) 下载。

**如果装完黑屏只有鼠标**：进 Recovery → 终端 → 运行 `finish-setup-auto.sh`
跳过设置向导，直接进桌面后再装驱动。

## 步骤 6：验证

```bash
# 显卡
system_profiler SPDisplaysDataType | grep -i "Chipset\|VRAM"

# Wi-Fi（关键）
log show --last 3m | grep -i yyavic
system_profiler SPAirPortDataType

# 亮度
log show --last 1m | grep -i backlight      # 期望：backlight registered

# 驱动状态
kextstat | grep -i nullmoth
```

**Wi-Fi 成功标志**：

```text
Card Type: Third-Party Wireless Card
Firmware Version: YYavicWiFi 0.8.0 (MT7922)
Country Code: CN
Local Wi-Fi Networks: ...（能扫到网络）
```

## 常见问题

### Q: 卡在 `pci (build ...)` 不动

检查 `UEFI → Quirks → ExitBootServicesDelay` 是否为 **3000**，
`Booter → Quirks → ProtectUefiServices` 是否为 **true**。

### Q: 改了 config 但参数没生效

看 OpenCore 日志的 `AAPL: #[EB|MBA:OUT]` 行是否含新参数。
没有的话，检查 `NVRAM → Delete` 是否包含 `boot-args`。

### Q: Wi-Fi 显示"未配置"或没有 Wi-Fi 图标

```bash
log show --last 3m | grep -i "yyavic.*disabled"
```

若出现 `native Wi-Fi layer disabled, unsupported macOS`，
说明 `-yyavicnoverify` 没生效（检查 boot-args）。

### Q: 加了 `-yyavicnoverify` 后内核 panic

回滚：在 Windows 下用备份的 `config.plist` 覆盖，或删掉该参数。

```powershell
# <ESP> 换成你挂载的 EFI 分区盘符
Copy-Item "<ESP>:\EFI\OC\config.plist.<备份名>" "<ESP>:\EFI\OC\config.plist" -Force
```

### Q: 没有声音

见 [docs/02-关键配置与踩坑.md](02-关键配置与踩坑.md) 第六节。
最快方案：**USB 声卡**（免驱）。

### Q: 亮度调不了

确认 boot-args 里有 `nvrmacpibl=1`，然后：
```bash
log show --last 1m | grep -i backlight
```
若显示 `no backlight` → ACPI 侧缺 NBCI `_DSM`，无法通过软件解决。

### Q: 按 Fn 键没反应 / 按 Fn+F 键系统重启

**这是已知未修复的缺陷，不是你的配置问题。**

| 操作 | 结果 |
|---|---|
| 单独按 Fn | 无反应 |
| Fn + F1…F12 | 🔴 系统重启 |
| 单独按 F1–F12 | 正常 |

**不要**试图通过删除 `BrightnessKeys.kext` 或修改 `SSDT-EC` 来修复。
调亮度请用控制中心滑块。详见
[docs/02-关键配置与踩坑.md](02-关键配置与踩坑.md) 第四节之二。

## 回滚

**任何时候改动 EFI 前，先做这个：**

```bash
# 把 EFI 备份到任意非 macOS 系统分区（示例挂载点，按你的实际情况替换）
cp -R /Volumes/EFI/EFI /Volumes/<你的备份盘>/EFI-backup-$(date +%Y%m%d)
```

出问题时把备份覆盖回去即可。
